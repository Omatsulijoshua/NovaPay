## Overview

**NovaPay** is a production-grade, full-stack peer-to-peer (P2P) digital wallet and payment platform built for the modern era of fintech. It enables seamless money transfers between users using unique 10-digit account numbers — much like traditional bank transfers, but powered entirely by modern web technologies.

NovaPay is built as **two parallel client applications** sharing a single unified backend:
- **Flutter mobile app** — a cross-platform native application (currently Android APK)
- **React web app** — a modern Progressive Web App (PWA)

Both connect to a **Supabase** backend that handles authentication, real-time database sync, secure financial transactions, and row-level security.

## Features

### Authentication
- Email & Password signup and login
- JWT-based session management via Supabase Auth
- Forgot Password flow with email-based reset link
- New Password update screen post-reset

### Wallet & Balance
- Every registered user automatically receives a **unique 10-digit account number** (auto-generated by a database trigger)
- An initial wallet is provisioned at registration
- Real-time **balance updates** via Supabase Realtime subscriptions
- Show/Hide balance toggle for privacy
- One-tap copy account number to clipboard

### Send Money
- Look up recipient by their 10-digit account number in real time
- Recipient full name displayed for confirmation before transfer
- Self-transfer prevention — users cannot send money to themselves
- Insufficient balance check with clear error feedback
- Transfer executed via a secure PostgreSQL stored procedure (transfer_money)
- Full receipt screen with transaction reference, amount, date, and parties involved

### Receive Money
- Auto-generated, shareable QR code encoding the users account number
- One-tap copy to clipboard for the account number
- Share account details with others

### Transaction History
- Full paginated list of all sent and received transactions
- Date-grouped display (Today, Yesterday, older dates)
- Search by description, reference, or name
- Filter tabs: All / Sent / Received
- Direction-colored icons (green = received, red = sent)

### Transaction Receipts
- Detailed transaction details screen
- Share receipt as plain text via native share sheet
- Print receipt — generates a PDF in memory and sends to native print spooler

### User Profile
- View account number, full name, email
- Secure logout with session clearing

## Getting Started

### Prerequisites

Make sure you have the following tools installed:

- [Flutter SDK](https://flutter.dev/docs/get-started/install) >= 3.0.0
- [Dart SDK](https://dart.dev/get-dart) >= 3.0.0
- [Node.js](https://nodejs.org/) >= 18.0
- [npm](https://www.npmjs.com/)
- [Supabase CLI](https://supabase.com/docs/guides/cli) (or use npx supabase)
- A [Supabase Account](https://supabase.com)
- [Git](https://git-scm.com/)

---

### Backend Setup (Supabase)

#### 1. Create a Supabase Project

1. Go to https://supabase.com and sign in.
2. Click **New Project**, give it a name, set a strong database password.

#### 2. Deploy the Database Schema via CLI

```bash
# Clone the repo
git clone https://github.com/Omatsulijoshua/NovaPay.git
cd NovaPay

# Initialize and link to your Supabase project
npx supabase init
npx supabase login
npx supabase link --project-ref YOUR_PROJECT_REF --password YOUR_DB_PASSWORD

# Push the full schema migration
npx supabase db push
```

#### 3. Enable Realtime

```bash
npx supabase db query --linked "alter publication supabase_realtime add table public.wallets; alter publication supabase_realtime add table public.transactions;"
```

#### 4. Retrieve Your API Keys

From your Supabase Dashboard > **Settings** > **API**:
- **Project URL**: `https://your-ref.supabase.co`
- **Anon/Public Key**: long JWT string

---

### Flutter Mobile App

#### 1. Install dependencies

```bash
cd novapay_flutter
flutter pub get
```

#### 2. Configure Supabase credentials

Edit `lib/main.dart` and update the default values:

```dart
const String supabaseUrl = String.fromEnvironment(
  'SUPABASE_URL',
  defaultValue: 'https://YOUR_PROJECT_REF.supabase.co',
);
const String supabaseAnonKey = String.fromEnvironment(
  'SUPABASE_ANON_KEY',
  defaultValue: 'YOUR_ANON_KEY',
);
```

#### 3. Run or build the app

```bash
# Run on connected Android device / emulator
flutter run

# Build release APK
flutter build apk --release
# Output: build/app/outputs/flutter-apk/app-release.apk
```

### React Web App

#### 1. Install dependencies

#### 2. Configure environment variables


#### 3. Start development server

```bash

```

#### 4. Build for production

```bash
npm run build
```

## Database Schema

### Tables

#### profiles
| Column | Type | Description |
|---|---|---|
| id | uuid | References auth.users.id |
| full_name | text | User display name |
| email | text | User email address |
| account_number | varchar(10) | Unique 10-digit account number (auto-generated) |
| created_at | timestamptz | Record creation timestamp |
| updated_at | timestamptz | Last update timestamp |

#### wallets
| Column | Type | Description |
|---|---|---|
| id | uuid | Primary key |
| user_id | uuid | References profiles.id |
| balance | numeric(18,2) | Current balance |
| currency | varchar(3) | Currency code (e.g., NGN) |
| created_at | timestamptz | Created timestamp |
| updated_at | timestamptz | Updated timestamp |

#### transactions
| Column | Type | Description |
|---|---|---|
| id | uuid | Primary key |
| reference | varchar(50) | Unique transaction reference |
| sender_id | uuid | References profiles.id |
| recipient_id | uuid | References profiles.id |
| amount | numeric(18,2) | Transfer amount |
| currency | varchar(3) | Currency code |
| transaction_type | varchar(30) | e.g., transfer |
| status | varchar(20) | e.g., completed |
| description | text | Optional note |
| created_at | timestamptz | Transaction timestamp |

### Database Functions (RPC)

| Function | Description |
|---|---|
| handle_new_user() | Trigger: auto-creates profile + wallet on signup |
| lookup_recipient(account_number) | Securely looks up a recipient by account number |
| transfer_money(account, amount, desc) | Atomic wallet debit/credit with deadlock prevention |
| get_transaction_history() | Returns full history with sender/recipient names resolved |

## Security

NovaPay uses a layered security approach:

### Row-Level Security (RLS)
All tables have RLS enabled. Users can only read and write their own data:
- **profiles**: Users can only view and update their own profile.
- **wallets**: Users can only view their own wallet.
- **transactions**: Users can only view transactions where they are sender or recipient.

### SECURITY DEFINER Functions
Financial operations requiring cross-user access run via `SECURITY DEFINER` stored procedures — preventing any direct client-side balance manipulation.

### Atomic Transactions
The `transfer_money` function executes entirely within a single PostgreSQL transaction:
- Pessimistic row-level locking (`FOR UPDATE`) on both wallets
- Locks acquired in sorted UUID order to prevent deadlocks
- Full automatic rollback on any failure

### JWT Verification
All API calls require a valid JWT. The `auth.uid()` function inside procedures verifies the callers identity server-side, making impersonation impossible.

## APK Installation

A release APK is available for direct installation on Android.

1. **Enable Unknown Sources** on your Android device:
   - Go to **Settings** > **Security** or **Privacy**
   - Enable **Install unknown apps** for your file manager

2. Transfer `NovaPay.apk` to your phone (USB, Google Drive, etc.)

3. Tap the APK file and press **Install**

4. Launch **NovaPay** from your app drawer!

> Minimum Android Version: Android 6.0 (API level 23)
